# 雾岭山庄谜案

纯静态网页侦探解谜游戏，无需安装依赖或构建框架。直接打开 `index.html`，或将仓库部署到 GitHub Pages 即可游玩。

## 当前版本

- 版本：2.5.0
- 8个调查地点、44件证物、12项推论、12次人物质证
- 开场侦探抵达过渡、初次侦探/独立调查两种模式、三级提示、存档导入导出
- 3种卷宗处理结局，其中包含“第十张”隐藏结局
- 1元自愿支持：首次进入调查后自动显示一次，也可从顶部“提示”旁手动打开；不验证付款，不影响谜题或结局

## 本地测试

安装 Node.js 后，在项目根目录运行：

```text
node tests/regression.mjs
```

测试覆盖数据引用、全部推论可达性、开放输入否定句、资源文件、付款入口、开场与发布清单。

## 生成修改文件包

Windows 下双击 `build_release.bat`。脚本会先运行回归测试，再生成：

```text
wu-ling-shan-zhuang_modified_release.zip
```

压缩包仅包含本次新增或修改的文件，保留原目录结构，可直接覆盖到现有仓库。
