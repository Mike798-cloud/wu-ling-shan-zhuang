# 雾岭山庄谜案

纯静态网页侦探解谜游戏，无需安装依赖或构建框架。直接打开 `index.html`，或将仓库部署到 GitHub Pages 即可游玩。

## 当前版本

- 版本：2.8.1
- 8个调查地点、44件证物、12项推论、12次人物质证
- 开场侦探抵达过渡、初次侦探/独立调查两种模式、三级提示、存档导入导出
- 3种卷宗处理结局，其中包含“第十张”隐藏结局
- 结案页输入、卷宗处理选项和隐私选择会实时保存，切换页面或刷新后仍可继续填写
- 三级结案提示逐项提供经过校验的参考答案，可直接填入且不会因标点、空格或合理否定语境误判
- 所有需要在推理板完成的提示都会明确标注操作入口：初次侦探显示具体证据链，独立调查只说明前往推理板，不泄露组合答案
- 顶部“提示册”按谜题分别保存一级、二级、三级提示；解谜后仍可回看，下一谜题从一级重新解锁，不会继承上一题层级
- 顶部“提示册”新增“本页提示”：切换地点或工具页后会重新判断本页是否能取得灰色条目；无线索时明确说明，有线索时按三级提示给出入口与前置条件，只有推理板页显示证据组合流程
- D05“餐厅后的第二次干预”和 D06“林岳伤后行动”现为独立主线目标：各自拥有三级提示、随页取证提示与推理板证据链，不会再只作为 D07/D12 中突然出现的灰色前置
- “终夜结案”三级提示改为独立滚动内容区：桌面低高度、平板和手机上均可向下查看九项答案，左侧提示记录不会抢占或截断正文滚动
- 1元自愿支持：首次进入调查后自动显示一次，也可从顶部“提示”旁手动打开；不验证付款，不影响谜题或结局

## 本地测试

安装 Node.js 后，在项目根目录运行：

```text
node tests/regression.mjs
```

测试覆盖数据引用、全部推论可达性、页面切换提示、灰色条目来源与前置条件、双模式推理提示、提示历史回看、逐题分级解锁、结案提示答案、草稿持久化、合理否定语境、资源文件与双难度目标。

## 生成修改文件包

Windows 下双击 `build_release.bat`。脚本会先运行回归测试，再生成：

```text
wu-ling-shan-zhuang_final-hint-scroll_modified_release.zip
```

压缩包仅包含本次新增或修改的文件，保留原目录结构，可直接覆盖到现有仓库。
